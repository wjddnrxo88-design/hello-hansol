# Hansol Recruit Blueprint

## Overview
Hansol Recruit is a modern, framework-less web application designed for a recruitment platform. It leverages modern web standards (Web Components, CSS Baseline) to provide a responsive and high-performance user experience.

## Project Details
- **Entry Point:** `index.html`
- **Styling:** `style.css` (using modern CSS features like CSS Variables, Flexbox, and Grid)
- **Logic:** `main.js` (using ES Modules and Web Components)
- **Components:**
    - `job-postings`: A custom element that displays a grid of job listings with filtering capabilities.

## Current Features
- Responsive navigation bar with sticky positioning.
- Hero section with a background image and search functionality.
- Job listings grid powered by a custom Web Component.
- Search filter for job titles.
- Placeholder sections for "인재상" (Values), "직무소개" (Job Descriptions), and "채용절차" (Process).
- Footer with copyright information.
